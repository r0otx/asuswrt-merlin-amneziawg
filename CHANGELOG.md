## [Unreleased]

### Features

- Tunnel lifecycle — `amneziawg.sh start/stop/restart/reload` backed by
  `awg-quick`; custom config generator supporting AmneziaWG 2.0 range headers
  (`H1-H4`) and I1-I5 signature packets; strict fail-fast validation.
- Handshake-based cron watchdog with rate-limit (max 3 restarts per 10 min
  window, 180 s stale-handshake threshold).
- `wan-event` handler with 5-second debounce; reacts only to
  `connected/disconnected/stopped` for primary WAN (unit=0).
- Auto-migration from v1 (with tarball backup to
  `/opt/etc/amneziawg/backups/`). Translates 25 known `amneziawg_*` keys to
  v2 `awg_*` schema; preserves unmigrated keys in
  `v1-unmigrated-keys.txt` for future modules.
- Stock Merlin WG client (`wgcN_enable=1`) detection (warn, non-blocking).
- `amneziawg.sh import` subcommand — reads `.conf` from stdin, validates,
  persists into `custom_settings.txt`.
- Status JSON at `/tmp/amneziawg/status.json` mirrored to
  `/www/user/awg_status.htm` for WebUI polling.
